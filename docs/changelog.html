v15.27

v15.272026-11-15
  • GIF 编码器性能与画质：LZW 压缩字典由 HashMap 改为扁平 IntArray(1<<20) + 代次戳，O(1) reset、全程零分配、无 GC 压力，GIF 导出更快更稳；输出字节与旧版逐字节一致（已在桌面 Python 端口 720p~4K 验证）。
  • GIF 调色板量化升级：6/6/6 桶改用桶内实际 RGB 质心替代固定网格中心，平滑渐变区阶梯色带大幅消除，零噪声、不增耗时。
  • MP4 / HEVC 导出绿幕修复：修正尾帧音频填充导致视频结束后整段绿幕的问题，并按真实解码终点校验，输出比真实终点短 800ms 以上一律丢弃 .tmp，绝不放行残缺 MP4。
  • GIF / 动图黑光晕修复：透明帧跳过阴影渲染（skipShadow），透明区域不再出现黑边光晕。
  • 导出管线精简：GPU 导出路径重构瘦身，选择器候选顺序更稳健，异常自动回退 CPU 逐帧。
  • 其它：移除不再引用的 RomGuard、内置字体与 NOTICE.txt；编辑器交互与多语言文案微调。
  • v15.27: GIF encoder reworked (flat LZW dictionary + generation stamp, byte-identical output, zero GC); centroid-based palette quantization removes gradient banding; MP4/HEVC green-screen fix and GIF transparent-frame halo fix; slimmer, more robust export pipeline; dropped unused RomGuard/bundled fonts/NOTICE.
  • 下载：GitHub Release v15.27（稳定版 / 测试版 / 源码 ZIP）。

v15.17

v15.172026-11-04
  • 修复：小米 / 红米 / POCO 澎湃系统（HyperOS，Android 13+）打开 App 即闪退的问题（已在澎湃真机验证不再闪退）。
  • 根因：HIGH 画质档的 AGSL RuntimeShader 在部分澎湃 Adreno / Mali 驱动的 RenderThread 层 native 崩溃（SIGSEGV），Java 层 catch 拦不住。
  • 方案：新增 RomGuard 兼容防护——澎湃系 + Android 13+ 默认切 LOW 档软件折射（保留法线折射 + 扭曲，不退化为磨砂），用户仍可在参数面板手动切回 HIGH；其它手机默认 HIGH 全量光学不变。
  • 自愈兜底：上次崩溃日志若含渲染 / GL 关键字，本次启动自动降 LOW 防止再次闪退；用户手动调过画质档则尊重用户选择。
  • Fix: launch crash on Xiaomi/Redmi/POCO HyperOS (Android 13+), verified fixed on a real HyperOS phone. RomGuard auto-selects the LOW software-refraction tier on HyperOS & AI-recovery downgrade; full HIGH optics unchanged elsewhere.
